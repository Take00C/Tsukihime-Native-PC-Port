FFmpeg: source and licence notice for the libraries shipped with this port

The game (Tsukihime.exe) decodes its sound (ATRAC9) and its movies (H.264 video, AAC audio) with the shared libraries of FFmpeg,
https://ffmpeg.org, loaded from the application folder at run time:

  avcodec-63.dll  avformat-63.dll  avutil-61.dll  swresample-7.dll

They are the unmodified DLLs of BtbN's "win64-lgpl-shared-9.0" build.
Build banner: n9.0.2-39-g7adfbe40dc-20261031.
Official release: https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-10-31-12-59
Binary archive: ffmpeg-n9.0.2-39-g7adfbe40dc-win64-lgpl-shared-9.0.zip on that release page.

Licence: GNU Lesser General Public License, version 3 or later (the build is configured with --enable-version3; avcodec_license()
answers "LGPL version 3 or later"). The licence text is FFmpeg-LGPL.txt next to this file; because the LGPL v3 incorporates the terms of
the GNU General Public License v3, that text is FFmpeg-GPL-3.0.txt beside it. No GPL component is in the build.

FFmpeg source commit: 7adfbe40dcde598f93a6963d2f7b22cd75202ccc on release/9.0, 39 commits after n9.0.2.
The n9.0.2 release tag is not this build's source revision.
Source: https://github.com/FFmpeg/FFmpeg/commit/7adfbe40dcde598f93a6963d2f7b22cd75202ccc
Source archive: https://github.com/FFmpeg/FFmpeg/archive/7adfbe40dcde598f93a6963d2f7b22cd75202ccc.tar.gz

BtbN build scripts commit: 5031c6f1082414e53688d39e521849905071070d, used by the dated autobuild.
Build scripts: https://github.com/BtbN/FFmpeg-Builds/tree/5031c6f1082414e53688d39e521849905071070d
Build scripts archive: https://github.com/BtbN/FFmpeg-Builds/archive/5031c6f1082414e53688d39e521849905071070d.tar.gz
The build uses ./build.sh win64 lgpl-shared 9.0, with addins/9.0.sh, variants/win64-lgpl-shared.sh,
the dependency recipes in scripts.d/, their patches in patches/, and the toolchain in images/base-win64/.
The scripts normally fetch the moving release/9.0 branch. To rebuild this revision, pin that checkout to the exact FFmpeg
commit above and use --extra-version=20261031. Download the two source archives separately from the links above.
The BtbN archive contains build and dependency recipes, not the FFmpeg source. Neither source archive is included in the binary ZIP.

The port loads the DLLs dynamically through the FFmpeg.AutoGen bindings, MIT, so they can be replaced by another build of the
same major versions, as the LGPL asks.
