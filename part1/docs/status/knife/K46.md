## 4. The Linux release

- Setup (never downloads): extract BtbN's `ffmpeg-n9.0-latest-linux64-lgpl-shared-9.0.tar.xz` to `third_party/ffmpeg/linux-src/`, run
  `python -I tools/setup/ffmpeg_linux.py`. It checks the four libraries (x86-64 ELF, SONAME), LGPL only (folder name, LICENSE.txt, no libpostproc,
  no `--enable-gpl`/`--enable-nonfree`, the licence string), the atrac9/h264/aac decoders through `bin/ffmpeg` (on Windows through WSL), and copies
  them with `LICENSE.txt`, `SOURCE.txt` and a generated `FFmpeg-SOURCE.txt` into `third_party/ffmpeg/linux/`.
- Publish: `dotnet publish src/Tsuki.App -c Release -r linux-x64 --self-contained -p:PublishReadyToRun=true -o <dir>` (or `publish_linux.sh`).
  `Directory.Build.props` bundles the four `.so` files and `licenses/FFmpeg-SOURCE.txt`, and stops with **TSUKI002** without them
  (`-p:TsukiBundleFFmpeg=false` for a system FFmpeg). `Tsuki.Distribution.targets` adds the licences (FFmpeg LGPL/GPL, SDL zlib, knife MPL, LICENSE,
  THIRD_PARTY, .NET) and `LINUX.md`. Builds and tests never need the libraries.
- Archive: `python -I tools/setup/package_linux.py <dir> --version X.Y.Z --out <dir>` writes `Tsukihime-vX.Y.Z-linux-x64.tar.gz`: one folder
  `Tsukihime-vX.Y.Z-linux-x64/`, 0755 for `Tsukihime`, `createdump` and every `.so`, 0644 otherwise, root owner, fixed times (reproducible).
- `release-check` on a Linux folder: x86-64 ELF player, `libSDL3.so` and the four FFmpeg libraries (ELF, LGPL build), the self-contained runtime, no libpostproc, no `.exe`,
  the ten licence files, a Linux `FFmpeg-SOURCE.txt`. On both platforms it refuses game data and any picture but the README's logo.
- `release-sums` checks a `Tsukihime-vX.Y.Z-linux-x64.tar.gz` (layout, modes, entry types, ELF, LGPL, `Tsukihime.dll` version/crescent/no personal mark,
  licences, no picture but the logo), refuses a zip and an archive of different versions, refuses any other picture in a zip, and lists both in `SHA256SUMS.txt`.
- `DisableTransitiveFrameworkReferenceDownloads=true` (Directory.Build.props): a linux-x64 restore needs two packages, not three.
