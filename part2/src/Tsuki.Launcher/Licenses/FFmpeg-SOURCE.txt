FFmpeg: source and licence notice for the libraries shipped with this port

The game (Tsukihime.exe) decodes its sound (ATRAC9) and its movies (H.264 video, AAC audio) with the shared libraries of FFmpeg,
https://ffmpeg.org, loaded from the application folder at run time:

  avcodec-63.dll  avformat-63.dll  avutil-61.dll  swresample-7.dll

They are the unmodified DLLs of BtbN's "win64-lgpl-shared-9.0" build of FFmpeg 9.0.1.
Build banner: n9.0.1-11-ge47273f4d9-20260831 (winget package BtbN.FFmpeg.LGPL.Shared.9.0 9.0.1-20260831).
Binary archive: ffmpeg-n9.0.1-11-ge47273f4d9-win64-lgpl-shared-9.0.zip, BtbN's autobuild of 2026-08-31 on
https://github.com/BtbN/FFmpeg-Builds/releases.

Licence: GNU Lesser General Public License, version 3 or later (the build is configured with --enable-version3; avcodec_license()
answers "LGPL version 3 or later"). The licence text is FFmpeg-LGPL.txt next to this file; because the LGPL v3 incorporates the terms of
the GNU General Public License v3, that text is FFmpeg-GPL-3.0.txt beside it. No GPL component is in the build.

FFmpeg source commit: e47273f4d9 on release/9.0, 11 commits after n9.0.1. The n9.0.1 release tag is not this build's source revision.
Source: https://github.com/FFmpeg/FFmpeg/commit/e47273f4d9
Source archive: https://github.com/FFmpeg/FFmpeg/archive/e47273f4d9.tar.gz
Build scripts: https://github.com/BtbN/FFmpeg-Builds as used for that autobuild (./build.sh win64 lgpl-shared 9.0, --extra-version=20260831).
BtbN's archive contains the binaries, not the FFmpeg source, and this port's download contains neither; get the source from the links above.

The port loads the DLLs dynamically through the FFmpeg.AutoGen bindings, MIT, so they can be replaced by another build of the
same major versions, as the LGPL asks.
