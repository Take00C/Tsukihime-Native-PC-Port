# L1: state-block contracts (PACE 7.1 L-1, ARCHITECTURE 3.2)

Status: **done** (generated accessors compile with `-warnaserror`, contract tests green, generator
re-run byte-identical). Nothing committed; the lead commits after review.

## What was done

- `src/Tsuki.Engine/Contracts/StateBlock.cs` (hand-written): `StateBlock` base (a fixed-size window
  of a `byte[]`, owned or a view at an offset; `Bytes`, `CopyFrom`, `ContentEquals`, `Clear`,
  little-endian typed helpers), `StateField` (one field-map entry) and `StateFieldKind`.
- `tools/setup/gen_state_blocks.py`: the generator. It reads the field maps from the Python oracle
  tables that the format documents name, checks them, and writes six `Contracts/Generated/*.g.cs`:

  | block | size | source tables (documents) |
  |---|---|---|
  | `SceneState` | 0x1A08 | `misc_adv_system_state.SCENE_STATE_FIELDS` + `misc_layer_state_and_motions.SCENE_ARRAYS` (layers.md 3, adv_state.md 2.6) |
  | `HistoryRecord` | 0x3A10 | `misc_adv_system_state.HISTORY_FIELDS`, `vm_vars.HISTORY_U16/_BOOL/_S8` (adv_state.md 2.1) |
  | `SoundChannelRecord` | 0x34 | table in the generator, checked against the sound_runtime.md 2.2 markdown table and `misc_audio_runtime_semantics.Rec.pack` |
  | `ConfigBlock` | 0x140 | `misc_adv_system_state.CONFIG_FIELDS` (adv_state.md 9.2) |
  | `SystemBlock` | 0x18AC | `eboot.savedata.SYSTEM_FIELDS` (adv_state.md 7.5, engine.md 7.3) |
  | `Vars` | 0x23F0 | `vm_vars` VAR_F / VAR_Z / VAR_G and counts (vm_variables.md 2.1, 2.2) |

  Generator checks (it stops with exit 2 when one fails): every map tiles its block; SCENE_ARRAYS
  and SCENE_STATE_FIELDS agree; the channel table equals the doc table and `Rec.pack`; F, Z, G are
  contiguous; the F lists have 39 / 43 / 276 entries; the config / system name tables (keyed by
  offset, since the oracle has descriptions only) still match the oracle offsets. When the game
  folder is present it also checks that the generated boot config equals the 0x140 bytes at VA
  0x66C578 of the eboot (it does); without the game folder that check is skipped and the output is
  the same.
- Accessor shapes: scalars are properties; arrays are `Get{Name}(i)` / `Set{Name}(i, v)` (per-layer
  arrays take `layer`, multi-value entries such as `Crop` take `(layer, index)`); opaque entries
  (`Motion`, `Ext`, history `Channel`) return `Span<byte>`, with typed sub-fields for motion
  (id, divisor, frames, pause) and ext (offset x / y, colour RGB); bit sets are
  `Get{Name}(bit)` / `Set{Name}(bit, b)`; nested blocks are cached views
  (`HistoryRecord.SceneState`, `.SceneCommitted`, `SystemBlock.Config`); every block has `Size`,
  `Fields`, `Clone()`. Extras: `SceneState.ResetLayer` / `CreateDefault` (layers.md 3 defaults),
  `ConfigBlock.CreateBootDefaults`, `HistoryRecord.FU16Indices / FBoolIndices / FS8Indices`,
  `SoundChannelRecord` record VAs, `Vars` F/Z/G aliasing (`GetF(1200)` = Z[0], `GetG(-1)` = Z[1399]),
  `FWordOfOperand` / `GWordOfOperand` / `CWordOfOperand` (s16 wrap, vm_variables.md 2.2), `GetC/SetC`
  (F[F823 + n]), `VaOfWord` / `TryWordOfVa`.
- `src/Tsuki.Engine/Contracts/SystemBlock.cs` (hand-written partial): picture_seen / bgm_heard /
  choice_taken helpers from gallery.md.
- Tests in `tests/Tsuki.Tests.Synthetic/Contracts/` (20 tests):
  - `StateBlockMapTests`: per block, sizes, `Fields` tiling, and for **every** field a write through
    its accessor that must change exactly the field's bytes (every entry / sub-value / bit), read
    back equal, and out-of-range indices throw; views at odd offsets; nested views share storage.
  - `StateBlockLayoutTests`: offsets typed in from the documents (layers 3, adv_state 2.1 / 2.6 /
    7.5 / 9.2, sound_runtime 2.2), defaults, and the vm_variables 2.2 examples (`F1200` -> Z[0],
    `F70000` -> G[1864], `F65535` -> 0x164B1CE, `G2000` -> 0x164D5C0, `G-1` -> Z[1399],
    C847 with F823 = 3 -> F850, F823 = 0xFFFF -> F846).
  - `StateBlockOracleTests`: equal to the Python oracle on the same bytes (commands below):
    `SceneState()` default SHA-256, boot config SHA-256 (eboot data image), `Rec.pack` bytes,
    `SceneState.layer_dict(7)` and `parse_history_record` on byte patterns, and all 356
    `history_f_values` (SHA-256 of the sorted list).
