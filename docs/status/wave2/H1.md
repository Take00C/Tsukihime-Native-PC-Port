- `Tsuki.App --pick-folder [--timeout S]`: exit 0 and `chosen: <path>`, 2 cancelled, 3 timed out
  (default 50 s, so the window always closes itself), 1 failed.

`Tsuki.App` is a WinExe. Its output reaches a terminal only through a pipe or a redirect: bash
waits for it; in PowerShell use `& $exe --smoke | Out-Host; $LASTEXITCODE`.

## Tests (`tests/Tsuki.Tests.Render/Smoke/`, 22)

- `GlSmokeTests` (GPU): a hidden window gets a 3.3 core context; the smoke shader draws the
  exact expected 8 x 4 pattern as GLSL 3.30 and as ES 3.00 (first pixel 16/32/153/255, last
  239/223/153/255); a broken shader throws `ShaderCompileException` with the driver log in both
  dialects; headers and defines.
- `PlatformSmokeTests`: virtual DualShock 4 hot-plug through the event pump (type `ps4`,
  Cross / Circle, removed and closed); Alt+Enter toggles through the pump; 9 hotkey cases
  (Alt+Enter, Alt+keypad Enter, F11 yes; plain Enter, Ctrl+Enter, repeats, Alt+Esc no).
- `AudioOutputTests`: pull mode, 48,000 frames pulled in chunks of 1..4,096 frames come out bit
  for bit, periods at most 1,024 frames; a throwing callback gives silence and reports the error.
- `FixedStepClockTests` (CPU, synthetic 10 MHz clock): 36,001 steps over 10 min exactly on the
  grid (S2's integer step of 166,666 units would be 24 ms early by then); a step reads its
  nominal time when the loop is 7 ms late; 1,440 jittered 144 Hz presents run steps 0..599 once
  each (600 presents with 1 step, 840 with 0); a 4-step stall catches up every step; a 200 ms
  stall runs 1 step, skips 10 and restarts the grid at now + 1 step (S2's formula gives the same 10).

## Notes for other packages

- **D1**: build on `Tsuki.Render.Gl` (`GlDevice.Gl`, `ShaderCompiler.CompileProgram(gl, dialect, vs, fs, defines)`).
  Every test that creates a window or pumps SDL events should use `[Collection(SdlCollection.Name)]`
  (SDL's event queue is process-wide; the collection disables parallel runs).
- **E1**: the device and pull streams are `Tsuki.Platform.AudioOutput` (`OpenDevice` / `CreatePullOnly`
  with an `AudioRenderCallback`), and FFmpeg loading is `Tsuki.Media.Ffmpeg.FfmpegLibrary.Load()`
  (idempotent, thread-safe).
- **Ordering**: tick consumers get `LogicTick.NominalTimestamp` (Stopwatch units) for S2's movie
  clock sampling; logic itself only sees `LogicTick.Frame`.
