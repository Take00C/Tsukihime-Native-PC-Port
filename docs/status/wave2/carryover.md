## research:quake
status: decoded
The per-frame quake, shake and swing formulas, the MSQK and SHOK screen quakes, and the RNG are decoded. The Python model `tsuki.quake` matches the engine's own code under unicorn bit for bit: 0 mismatches over about 15,300 compared updates (every field of all 40 x 2 slots, the MSQK and SHOK globals, and the rand state after each update).

RNG: `rand()` lives in the game's own `sce_module/libc.prx` (rand at libc 0x1C290, srand at 0x1C310). It is a single global u64 LCG that starts at 1: `state = state*0x5851F42D4C957F2D + 1`, returning `(state>>32) & 0x3FFFFFFF` (RAND_MAX = 2^30-1; the engine multiplies by 2^-30). `srand(seed)` stores `(uint32)seed`. The game seeds it twice. At boot (0xD212E) the seed is an uninitialised stack byte, because the clock calls there are stubs. At every title-screen init (0xAFE80) it calls `srand(minute*256 + second)` from sceRtcGetCurrentClockLocalTime. The same state is shared by 145 call sites in 25 functions, including text animation, transitions and SE choice. So a PS4 run cannot be replayed exactly; the port gets exact values for a given seed and call order. A second generator 0xE8200 (state at 0xDC7BF0, initial 0x6F37) drives SHK2's flicker. 0xC2F90 gives a uniform value on a 2^-20 grid for MSQK.

Per frame (0x57F4D..0x5889A): layers 0..39 in index order (used or not), slot 0 then slot 1. The common part handles the start delay (the field layers.md calls "fade"), skips a slot with time 0, saturates elapsed at 30000, and clears the slot when
