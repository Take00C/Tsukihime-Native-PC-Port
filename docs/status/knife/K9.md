## 2. What the player sees

* **Auto** (the default): keyboard and mouse show key caps; a PlayStation pad shows the game's icons (with CROSS as decide, as the app does); any other pad shows Xbox glyphs.
  A fixed setting wins over the device. The first screens (boot notice, title) follow the keyboard until a pad is touched.
* **Config > Controls > Button Prompts**: a row of four pills (Auto, Keyboard, PlayStation, Xbox) in the blank header band at the top of the controls page, reachable
  with the cursor (Down from the tabs, Left / Right, Decide), the mouse and the saved file. Heading and Auto / Keyboard are translated (ja ボタン表示 / 自動 / キーボード,
  zc 按键提示 / 自动 / 键盘, zt 按鍵提示 / 自動 / 鍵盤; every glyph exists in the pages); PlayStation and Xbox stay English.
* **Controls page**: PlayStation style = the PS4 picture; Keyboard and Xbox style keep the game's own labels, row lines and the mouse rows below and replace the icon column
  of the 12 controller rows by key caps or Xbox glyphs (Enter Space Z; X; Esc M; PgUp I; arrow up; arrow down; Tab E; A Q; Ctrl; Backspace; mouse PgUp PgDn; F5).
  The picture is drawn in pieces that leave a 48-row box around each icon out and the box is filled with 6-row slices of the page's flat band taken just above the icon
  (same x, so the band's horizontal gradient matches; the page is a translucent band, so icons cannot be painted over). Measured against the PlayStation render in the replaced strip right of the glyphs: 0 outside it, at most 5 of 255 in ten rows and 12 to 13 in the first and the last row (the band is not quite flat vertically); not visible in the PNGs.
* **Title**: PRESS ANY KEY (the game's glyphs, wide spacing, the same pulse) replaces the bitmap PRESS ANY BUTTON in the keyboard style only.
* **`--prompts auto|keyboard|playstation|xbox`** on `Tsuki.App` sets the style for one run (saved only when the player changes it in the config screen).

## 3. Bindings changed, and why

The guide must name keys that do what its word says, and every guide action needs a keyboard binding:

| change | reason |
|---|---|
| `Delete` is a shell action of its own (`ShellActions.DeleteData`), no longer SQUARE | save list: Delete Data |
| Page Up / Page Down are shell actions (`PageUp`, `PageDown`); menus read them as five wheel steps (`UiInput.PageSteps`), so every list that scrolls by wheel scrolls a page (save list: cursor 5 rows, config 300 px, chart 840 px, CG grid 5 rows, music list 5 rows) | the guide's Scroll shows wheel, PgUp, PgDn |
| TRIANGLE is a pad button only (Page Up and I no longer set it) | the save list's TRIANGLE is now Delete Data; a scroll key must not open a delete dialog |
| the story still opens the backlog with Page Up / I / wheel up (the `Backlog` shell action); inside the backlog `I` closes it again (shell Backlog without wheel steps), Page Up / wheel scroll | keeps K6's toggle |
| save list: TRIANGLE (pad north) and Delete = Delete Data, SQUARE (pad west) and M = Copy Data | see errata below |

README's input table has the new rows (wheel / page keys, Delete, M) and a "Button prompts" paragraph; `InputMapper.Bindings` was updated.

### Errata for K5a / K6

* K5a open issue 2 and `GuideSaveList` said the save list's north button is **Copy Data**. The word beside the TRIANGLE icon in guide sequence 11 is **word 18, "Delete Data"**
  (`guides` scene, `guide-cells` scene; en "Delete Data", ja データ削除). The screen did the opposite (TRIANGLE = copy, SQUARE = delete), so the PlayStation guide lied. The screen now
  follows the guide (PS4 data wins); Copy Data (dialog 24) stays reachable on SQUARE and has no guide word (no sequence has word 19).
* `UiSheets.ConfControlsMouse` (CONF_PARTS 16 / 17) was described as "the controls page for the mouse" and never drawn. Both sheets are the **same page**, 16 with CIRCLE as decide and
  17 with CROSS as decide (the Confirm and Cancel rows swap their icons); the mouse rows are the lower part of both. The app has `DecideIsCross = true`, so the config page showed
  CIRCLE for Confirm while the guide showed CROSS. Renamed `ConfControlsPadCross`, chosen by `DecideIsCross`.
* K6's key table said "Q / E, Delete: previous / next tab; delete in the save list (Square)": Delete is now its own action (above).
