### Frame model (what the host does, in order)

1. `Step` copies the frame's input into `WaitInput`; the mode words toggle (`L1` auto, `R1` skip latch, cancel clears it, hold `R2` / Ctrl = fast-forward); the
   read-only rule (config +0x30) stops skipping on an unread line before the update and again after `Adv_Update`.
2. `WaitModel.AdvUpdate`: clears the advance latch, ends the voice bit, evaluates `_STCF`, the plain voice wait, the message wait (click / auto / skip / no-click
   advance), the restored-page cases; when `bits == 0 && timer == 0 && auto == 0 && no fade` it lets `Script_Step` run: `ScriptVm.Step(this)` runs statements until
   one yields (a `_ZM` yields; so do `MSAD CLO2..5 WTTM WTSV FADS STCF SEL* TOMP TOMW VCWT-with-voice JUMP`, the `IF__` / `GOTO` jumps yield in the VM).
3. `WaitModel.TickReveal`: reveal head / tail in float32, click completion, `_WTTM` countdown and cancel, auto countdown, reveal-done (0xCA070 over the message's
   glyph records), choice flag.
4. `StageRuntime.Update(step)`: tweens, motions, the commit transfer and the transition; the `_FADS` wait bit clears when no transition is active.
5. Choice machine, movie state, sound update (`SoundModel.Update`, ducking, commands to the virtual or real audio), window / text fades, effects.
6. Draw (when a list is given).

The wait numbers are those of wait_model.md and are checked in the tests: a 20-glyph `@e` message started in frame 0 is revealed in frame 47 and advanced in 48;
`_WTTM(1000,1)` resumes at frame 60; `_FADS(1,0,0)` holds the script 2 frames; auto advances at reveal + 132 + 1 (180 + 1 at a page end); the decided phase of a
choice ends on its 51st frame; one press never both completes and dismisses a message.

## PS4 versus Switch (knife) and corrections found

1. **`_IF__`**: script.md 4.1 reads "if var op value then goto label". The VM (verified under emulation, C2) and knife agree on the opposite: it **jumps when the
   condition is false** (`_IF__(F057,ne,1,LV)` jumps when F057 == 1). The host never sees `IF__`; documents that quote it as "then goto" should be read the other way.
2. **`_IFSC` is a system condition, not F024.** The ARCHIVE scene tests `IFSC` first and sets F024 / F025 itself only when it does not jump; the host keeps a
   `ReplayRequested` flag (set by `StartReplay`) for it. `F024` is then the replay marker the other commands test (`RTST` stores F110, `RDED` ends the script).
3. **`_STMA` without a wait argument sets F1103** (word 0x164BA6E = F1103, the "text hidden" word) and `_FADS`'s fourth argument does too (knife: 1, or 2 under a
   condition). wait_model.md's worked example for `00_00` is a linear plan: it has no `IF__` yield and no F1103 from `_STMA(3,1)`, so its first message starts in frame 294 and
   its text is already faded in; the engine flow starts it in 293 and fades the text in over 18 frames after the window (17 stalled frames, not 16). The revealed frame (410), the next
   start (471) and its reveal (556) are the same as in the document (test `ThePrologueNarrationRunsOnTheFramesOfTheWaitModelWorkedExample`).
4. **The flowchart jump keeps F026 as a signed byte on both consoles** (it is on the byte list of the PS4 eboot too), which cuts a scene id to its low byte (372 -> 116, 512 -> 0).
   Scripts only test `F026 != 0` after a jump, but an id whose low byte is 0 would then skip its jump-entry block. The host sets F026 and F110 again, whole, after the restore.
5. **Scene 260 does not complete node 485**: `_RDED(485)` marks scene_done only when F110 == 485, and nothing stores F110 on a New Game start (F110 is set by the `_JUMP` edge code
   and by `_RTST` for the QA nodes). The New Game rule needs scene_seen(485) only (`_RDST`), so the first run of the game starts the prologue, the second `START_SCRIPT`.
6. **`_MFAD` waits in word 0x1653E08** (the `_WTTM` timer), `ms / 16` frames, and leaves the timer's click flag as the last wait set it (sound model's `Wait16`).
7. **The window and text fade arithmetic is the sim's** (`tsuki.wait_model.Simulator._fade_update`): the text step ends only when the alpha leaves 0..1 (`> 1`, not `>= 1`).
8. **Choices**: knife keeps its own per-line state; here the lines are `$` + 6 digits of the prefix line (43960 + k, the tenth is 43959) + argument 1, as system_flow.md 5.1 gives; the
   cursor starts at -1; locked lines are skipped by up / down and cannot be decided (the PS4 draws them like the others, system_flow.md 5.3: the draw here does the same).
9. **Boot**: the PS4 has no logo screen; notices then title. The headless runner prints the boot as the trace header (`# boot: fresh profile ...`) and starts New Game with
   `NewGameSceneId()` (bit 485 clear -> 260, else 110); the title screen itself belongs to Tsuki.Ui.
10. knife's Witch / Switch-only commands (`CLO6`, `WTIN`, `XSKR`, `XSOF`, `TTCT`, `CKDP`, `CKTT`, `SPIA`, `SPAB`, `STSW`, `STQS`, `SEWI`, `VLOG`) are not in the PS4 table and are not handled.

## Open issues and what is left for the integration package

K4's API is wired as far as the interpreter can: `AttachHistory()` plugs `AdvHistory` into every push site (message, layer batch / commit, music, effects, scene start,
choice point, choice start / line), `SceneStackPush`, `UpdateStaging`, `OnMessageShown`, `SetNewestVoice`, `AutoSave` (to a `SaveStore`).

**Left for the integration package** (nothing of it blocks playing the story):

1. **Applying a `RestoreOutcome`** (rewind, previous scene, backlog jump, load). The ring restores `AdvLiveState`; the host still has to: seek the VM to `live.ScriptOffset` /
   reload `live.ScriptNumber`; copy `live.Scene` into `Stage.Scene` and rebuild the stage (committed copy for kinds 1 / 9); restart the BGM (`Bgm`, `BgmTrack`, `BgmVolume`) and the
   looping effects (`LoopSe[]`) through the `SoundModel`; re-display the message (`Redisplay`) and set the wait bits (`WaitFlags`, `WaitFlags70`, `Word1653E08`); clear the
   skip latch; `Adv_Rewind` itself (hold-L2 loop with its wait checks) and the backlog list UI call these.
2. **`AdvLiveState` members the host cannot fill yet**: the name-plate bytes (`Window164FD00 / 40 / 60`), the speaker byte (`Speaker`), the deferred-SE channel table at
   0x16543F0 (`Channels`, the sound model keeps its deferred queue privately), the SE word at 0x1654300 (`SeArrD`), the effect-slot bits (only the movie sets bit 0 as "blocking"),
   `State174DAB0`, `Var174D940`. Their record bytes stay zero.
3. The `SavePromptAccepted` event (the "yes" of `_SELA`) must open the save screen; `SaveStore.AutoSave` receives the staging of `_ATSV(8)` but the thumbnail is not captured.
4. The sound after a next-scene skip: `SceneSkipEnded` is raised; the BGM / loop restart from the script state (0x7E620) is the caller's (it needs the model's script-side state).

**Rendering gaps** (state is complete, the draw is not):

5. **Focus effect `FCLN` / falling notes and the ghost effect `FADE(40)`**: `GameHost.FocusState / FocusEffect / FocusLevel` and `GhostMode / GhostAlpha` follow the commands; the particles
   (up to 400 focus lines, 50 notes) and the channel-split pass are not drawn.
6. **Choice draw**: the lines are drawn; the cursor glow copies (8 per line), the underline, the flare, the vignette, the ring and the blue bands of system_flow.md 5.3 are not.
7. **UI sheets are one whole-sheet quad** (`TextureRef.ForUiTile(set, lang, child, tile: -1)`, uv 0..1): the executor must map tile -1 to the whole sheet (it does not know UI tiles yet).
   The window sizes come from decoding the sheet once per child (`SheetSize`).
8. The click icon, the mode icon, the name plate and the second window (F1111..F1113) are not drawn; the message quake offsets are applied to the page.
9. `WindowHidden` (action 25: cancel or the shell's H) hides the window and its text; the HUD pieces that stay while hidden are not distinguished.

**Other**:

10. `XSTP` / `XRSM` only set / clear F36 (the staff-roll system state 0xB is not modelled); the two scripts that use them run to their end in the coverage run.
11. The movie state's UI sound (VA 0x5E490) is not played; `movie_seen` is stored for the six ids with a known bit (4, 5, 6, 35, 36, 37).
12. Language switch during a story (config language change relays out the page) is not implemented; the language is fixed per `GameHost`.
13. `jump_special` of knife (the ~500-case pair switch of the flowchart edge marks, PS4 function 0xB9460) is not ported: a scene jump marks the plain edge from the eboot table; the
    special pairs (hidden nodes 497..530) are not marked. Only the gallery flowchart colours depend on it.
14. The explorer's abstraction (control flow = the variables `IF__` / `GOTS` read and the copies feeding them; `RDED` / `IFUR` ignored) is checked by replay in the full engine; it is not a proof of
    unreachability, only of reachability (see Coverage).
