# ADV text box (alias)

The documentation for the "adv_textbox_layout" coverage gap (message window, main text box,
automatic line breaking, ruby placement, reveal and wait model) is
[`textbox.md`](textbox.md). The Python reference is `tools/tsuki/textbox.py`
(`tools/tsuki/misc_adv_textbox_layout.py` re-exports it). Samples are in `samples/textbox/`.
