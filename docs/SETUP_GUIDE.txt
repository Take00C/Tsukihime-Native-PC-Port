=======================================================
Tsukihime PC port: the player's setup guide (セットアップガイド)
=======================================================

This guide is for players, not developers. It tells you what the port is, what you need, how to get
your own game files into the shape the port reads, how to start it the first time, how to play, what
Japanese learners can switch on, and what to do when something goes wrong. It describes version
0.1.0 of the programs (Tsukihime.exe and TsukihimeLauncher.exe) as they were on 2026-10-30; the
launcher's Help page and the README carry the same facts in shorter form. The download holds this
guide as SETUP_GUIDE.txt next to the programs, and the launcher's Help & about page has a button,
Open the setup guide, that opens it.

The short version: unzip the port anywhere, start TsukihimeLauncher.exe, point it at your own
extracted CUSA47999 game folder on the Game files page, press PLAY.

1. What this is (これは何か)
-----------------------

Tsukihime PC port is an unofficial fan project. It is not affiliated with, endorsed by or supported
by TYPE-MOON, Aniplex, HuneX or Sony. TSUKIHIME and all of its art, music, text and characters
belong to their rights holders.

It is a native Windows version of the engine of TSUKIHIME -A piece of blue glass moon- (PlayStation
4, title id CUSA47999): a clean reimplementation, written from a study of the game's data formats
and of the behaviour of the console program. It is not an emulator and it does not run the PS4
program. Every time it starts, it reads the files of your own copy of the game and plays them with
sound, movies, menus, saves, backlog, rewind, flowchart and gallery, in Japanese, English,
Simplified Chinese and Traditional Chinese.

The port contains no game data. The download holds the port's own programs and libraries and nothing
from the game: no pictures, no sound, no text, no fonts, no eboot.bin. You must supply the game
files yourself, from a copy you own. Downloading a game you do not own is piracy; this project does
not support it, and does not provide game files or links to any source of them.

The port never writes into your game folder. It opens the files read-only. Your saves and settings
live in your Windows profile (section 5.7).

1.1 The verified build, and what is untested

The port was played end to end on one build: the Asian release CUSA47999 (the one that carries
Japanese, English and both Chinese variants), application version 01.01, that is the base game with
the official 1.01 update applied. The program knows that update's eboot.bin by its size and SHA-256
and shows it as known build: CUSA47999 01.01 (official 1.01 update eboot). A second eboot.bin is
known too, the 1.01 program file of the "backport" update package made for older console firmware
(CUSA47999 01.01 (1.01 eboot of the 5.05 / 6.72 / 7.xx backport)); its game tables are byte for byte
the same as the official one's, so it runs the same way.

Honestly untested, because no such copy was available while the port was built:

- Other releases of the game (a Japan-only release, any release with another title id) and a 01.00
  base game without the update. The port does not refuse them outright: for any eboot.bin it does
  not know, it searches the program file for the tables it needs and checks each one before use. If
  every table is found, the game runs and the launcher says Ready, but not the verified build. If
  one is missing, the game refuses to start with a message that names the build and the missing
  tables and asks you to report it with the log (section 7).
- Korean. The Asian release has a Korean slot without real text or fonts, so Korean is never
  offered.
- A real game pad in hand. Pads are supported through SDL3 (PlayStation and Xbox-style pads, button
  prompts that follow the pad), and the mapping was tested with simulated input; nobody plugged a
  pad in during development.
- A second monitor, and the text-hooker programs of section 6 (LunaHook, LunaTranslator,
  Textractor): the port does what those programs' documentation says they hook, but they were not
  run against it.

2. What you need (必要なもの)
------------------------

You need / Notes

  Your own copy of the PS4 game
      Notes: TSUKIHIME -A piece of blue glass moon- for PlayStation 4, as extracted files (section
      3). The game folder is about 44 GB (44.1 GB as Windows counts it); the separate update folder,
      if you keep it, about 400 MB.

  Windows 10 or 11, 64-bit
      Notes: The programs are 64-bit Windows programs. Everything they need (the .NET runtime, SDL3,
      FFmpeg) is in the download; there is nothing to install.

  Any graphics with OpenGL 3.3 (no gaming card needed)
      Notes: Laptop integrated graphics are fine: Intel HD / UHD / Iris (about 2012 on) and AMD
      Radeon integrated graphics all have it, as does any desktop graphics card of the last ten
      years. The port draws a 1920 x 1080 picture with a few layers and adapts its picture memory
      to the graphics chip (512 MB at least). The game checks OpenGL 3.3 when it starts and says Your graphics driver does not provide OpenGL 3.3 when it fails.
      Remote-desktop sessions and some virtual machines have no OpenGL 3.3.

  Disk space
      Notes: About 44 GB for the game files plus about 260 MB for the port (the zip is about 105 MB,
      unpacked about 250 MB), plus a few MB for saves and screenshots. The game files can sit on any
      drive, an external one too; the game reads them in place and does not copy them.

  Input
      Notes: A keyboard and a mouse, or a game pad.

  Sound
      Notes: Any Windows audio device. The game also runs without one.

3. Getting your game files (ゲームデータの用意)
--------------------------------------

3.1 What the port reads

The port reads the game's extracted application folder: the folder that holds eboot.bin (the game's
program file), image\ (the picture, sound, text and movie archives) and sce_sys\ (with param.sfo,
the game's description). Extraction tools name this folder after the title id, CUSA47999. If you
also have the game's update (patch), it is either already merged into that folder or sits in a
second folder beside it; both are fine (section 3.3).

There are two ways to such a folder, and both start from a copy you own.

3.2 Two routes

Route A: dump your own copy from your own PS4. A PlayStation 4 that can run homebrew software can
copy an installed game (disc or digital) to a USB drive with a game-dumping application, as a .pkg
file or directly as the extracted folder. The shadPS4 emulator project documents how its users dump
their own games; follow its official documentation and nothing else:
https://github.com/shadps4-emu/shadPS4 (the README and the documentation folder; the project's wiki
pages belong to the same repository). This guide does not describe how to run homebrew on a console
and does not link to anything but that project page. Dump the base game and, if the update is
installed on the console, the update as well.

Route B: you already have your own copy as .pkg backups. A .pkg is a sealed package; the port cannot
read it (if you point the launcher at one it answers A .pkg file was chosen: extract it first, then
choose the extracted CUSA47999 folder). Extract the game .pkg, and then the update .pkg if you have
one, with a PKG extraction tool into a folder of your choice. The shadPS4 documentation above
describes the tools its community uses for this; the port's own messages say the same (Extract it
first: shadPS4, or a PKG extractor). If your update came as a "backport" package for older console
firmware, that is fine too: its program file is one of the two the port knows.

Never download games, licence keys or console firmware. A download of a game you do not own is
piracy and is not supported here.

3.3 What the finished folder looks like

After extraction you have one of these two shapes (the parent folder D:\Games\ is an example; any
drive and any parent folder will do):

    D:\Games\
      CUSA47999\                   the game (eboot.bin and image\ are what the port looks for)
        eboot.bin                  the program file; the port identifies your build by it
        sce_sys\
          param.sfo                title, version, title id (the window title is read from here)
          ...                      icons, licence files and manifests the port does not use
        image\
          allpac0.hed  .nam  .mrg  pictures, UI sheets, sounds, scripts and text: 20 archives and data files
          allpac1.*  allpac1_2.*  allpac2.*  allpac3.*  allpac4.*
          bgm.*  vag.*  voice.*  voice2.*  vse.*  parts.*  se_nam.mrg
          allscr.mrg  script_text.mrg  corp.png
          ft_ja.mrg  ft_en.mrg  ft_zc.mrg  ft_zt.mrg  ft_ko.mrg
          movie\
            *.mp4                  134 movies
        data\
          if_ja.png  if_en.png  if_zc.png  if_zt.png
        sce_module\  sce_discmap.plt  eboot.fself   (present in many dumps; not used)

      CUSA47999-patch\             the update, when the extractor put it in its own folder
        eboot.bin                  the updated program file
        sce_sys\param.sfo          says version 01.01 and category "gp" (a patch)
        image\                     only the files the update changes
          allpac3.hed  allpac3.mrg  allscr.mrg  script_text.mrg

Where the update folder goes. Side by side with the game folder, in the same parent, under the game
folder's name plus a suffix: CUSA47999-patch (some PKG extractors), CUSA47999-UPDATE (shadPS4),
CUSA47999_patch, CUSA47999-update or CUSA47999_update, in any letter case. A base folder named
CUSA47999-app next to CUSA47999-patch is understood too. The port recognises an update folder by its
param.sfo (category gp), or by the suffix when there is no param.sfo. The two folders are read as
one game: the update's files take precedence over the base's, and the update's eboot.bin and
param.sfo are the ones that count, as on the console. There is one exception: when the game folder's
own eboot.bin is already a known 1.01 program file (a merged dump with a leftover update folder
beside it, as some extractors' install step leaves behind), the game folder is used as it is and the
launcher notes that the update folder is not needed.

An update folder alone cannot be played: the launcher says Only the update folder was found; the
base game must be beside it.

3.4 Checking the folder

Start TsukihimeLauncher.exe, open Game files, press Browse… and choose the folder. You may choose
the CUSA47999 folder itself, the folder above it (the game is found one or two levels down), a
folder inside it (image\, data\, sce_sys\) or the file eboot.bin: all lead to the same game. You may
also type or paste the path into the box and press Enter.

A good folder shows, on the Game files page:

- Status: Ready: this is the game the port was made for (the verified build), or Ready, but not the
  verified build: … (another build whose tables were all found; the game runs).
- Title and version: CUSA47999 · version 01.01. The base package's own param.sfo says 01.00, so a
  merged dump adds (param.sfo says 01.00); the version shown is the one the program file is
  identified as.
- Build: known build: CUSA47999 01.01 (official 1.01 update eboot), with a note about an update
  folder beside the game when there is one (its files take precedence, or is not needed).
- Languages: 日本語, English, 简体中文, 繁體中文 (the languages your copy carries; a language that is missing
  from your dump is not offered anywhere).
- Size on disk: about 44 GB. Build checks: all passed, for example 78 of 78 passed. Contents: 20
  archives and data files, 134 movies.

A folder with a problem shows the reason under the path box (section 7.1) and the failed checks as a
list.

4. First start (はじめての起動)
------------------------

4.1 Unpack

Unzip the release into any folder you like, for example D:\Tsukihime PC port\. There is no installer
and nothing is written to the registry. The folder holds TsukihimeLauncher.exe (the launcher),
Tsukihime.exe (the game), their libraries (about 280 files: the .NET runtime, SDL3.dll, the four
FFmpeg libraries), README.md, this guide as SETUP_GUIDE.txt, and a licenses\ folder with the
third-party notices. Keep all of it together: the game loads its libraries from its own folder, and
the launcher starts Tsukihime.exe from beside itself.

The programs are not code-signed, so Windows may show a SmartScreen notice the first time you start
one ("Windows protected your PC"): More info, then Run anyway. That is a Windows notice about
unknown publishers, not a finding about the file.

4.2 The launcher

TsukihimeLauncher.exe is the front door. Its sidebar has seven pages: Play, Game files, Display,
Language & sound, Controls, Saves, Help & about. The footer shows a status line (the window size or
monitor, the mode, the language, the button prompts), a Log button and a big PLAY button. The
launcher itself is in English; the game is in the language you choose.

Only one launcher runs at a time (The Tsukihime launcher is already open), and only one game.

4.3 Game files

The first thing to do: Game files > Browse…, choose your CUSA47999 folder (section 3.4). The
launcher checks it (a moment: it reads the program file and lists the archives) and remembers it in
%APPDATA%\Tsuki\game_dir.txt, where the game reads it too. Nothing in the folder is changed. A
folder that is not the game is not remembered, and the sentence under the box says why.

4.4 The Ready check

Back on Play, the Ready check card has five rows, each with a check mark or a warning sign. A row
with a warning has a Fix link that opens the page where it is fixed.

Row / What it checks / What it says when it is fine

  Game folder
      What it checks: The folder is set and holds the game; which build
      What it says when it is fine: CUSA47999 found, version 01.01: verified build (and update
      folder … beside it when there is one). … : other version of a known release … tables found by
      content is a warning with a Fix link: the game runs, but on a build the port has not played.

  Game files
      What it checks: The archives, the movies and the program tables
      What it says when it is fine: 20 archives and 134 movies verified (or checked; 66 tables
      located by content in 0.4 s for another build)

  Game program
      What it checks: Tsukihime.exe and the FFmpeg libraries are next to the launcher
      What it says when it is fine: Tsukihime.exe and the FFmpeg libraries found

  Graphics
      What it checks: The name of your graphics adapter
      What it says when it is fine: … ; OpenGL 3.3 is checked at start. The launcher cannot test
      OpenGL itself; the game does, in its first second.

  Saves
      What it checks: The save folder can be written; what save.dat holds
      What it says when it is fine: No saves yet; they are created on the first play or 12 save
      slots in %APPDATA%\Tsuki

The chips under the banner say the same in one line: CUSA47999 · game version 01.01, plus not the
verified build for another build, plus the launcher's version.

4.5 Quick settings, Display, Language, Controls

Quick settings (Play page): the game language (only the languages your copy carries are shown), a
Fullscreen switch, the Button prompts style and the Desktop shortcut row. The same choices with more
room are on their own pages:

- Display: Fullscreen (borderless fullscreen on the chosen monitor; off, the game opens as a
  window), VSync (on by default; turn it off only if the picture stutters), the Window size presets
  (1280 × 720, 1600 × 900, 1920 × 1080, 2560 × 1440: only the ones that fit the chosen monitor are
  offered; the default is 1600 × 900), the Monitor to open on, and the graphics adapter's name. The
  game's window is a real window with a title bar, centred, never larger than 90 % of the monitor's
  work area (a size that does not fit is scaled down, 16:9 kept; the note under the presets says the
  size the game will open with), and a size you drag the window to is remembered. In the game,
  Alt+Enter or F11 and Config > System > Display Mode / Window Size change the same things, and the
  launcher shows what the game last chose.
- Language & sound: four tiles for the game language (Japanese, English, Simplified Chinese,
  Traditional Chinese). It takes effect at the next start; inside the game, Config switches it at
  once, and the window title follows (月姫 / TSUKIHIME / 月姬 -A piece of blue glass moon-). The voices
  are Japanese in every language, as in the original. Volumes are not set here: they are saved with
  your progress, so they live in the game's own Config > Sound.
- Controls: Button prompts (Auto shows key caps for the keyboard and mouse, the game's own
  PlayStation icons for a PlayStation pad and Xbox glyphs for any other pad, following the device
  you used last; Keyboard, PlayStation and Xbox pin one style), the full key table (section 5.1) and
  the game controllers Windows reports as connected.

Everything these pages change goes into a small text file, %APPDATA%\Tsuki\settings.ini, which the
game reads when it starts (appendix A).

4.6 PLAY, the desktop shortcut, and Tsukihime.exe on its own

PLAY starts Tsukihime.exe from the launcher's folder with your game folder, the window mode of the
Fullscreen switch, and a log file (%APPDATA%\Tsuki\last_run.log). The button reads RUNNING while the
game is up; the launcher minimises and comes back when the game ends. If the game ends with an
error, a toast says The game closed with an error (code N). Press Log to see why.

You do not need the launcher every time. Desktop shortcut (Play page, under the quick settings, or
Game files > Shortcuts) puts Tsukihime.lnk on your desktop; Game files > Shortcuts also makes a
desktop shortcut to the launcher and Start menu entries (Start menu > Programs > Tsukihime). A
shortcut that already exists is replaced only after you confirm. The game's shortcut and window
carry a small portrait of Arcueid as their icon, cut at run time from your own copy's files and
stored in %APPDATA%\Tsuki\icons\; the bare .exe files keep the port's own crescent moon.

Starting Tsukihime.exe directly (a double-click, or the shortcut) works once the folder is known: it
uses the remembered folder and the same saves and settings. On a machine where no folder was ever
chosen, the first start explains in your Windows display language what it needs (Tsukihime needs
your own copy of the PS4 game. In the next window, choose the extracted CUSA47999 folder …) and
opens a folder dialog; the choice is remembered. A wrong folder is explained the same way. Started
directly, the game writes no last_run.log (section 7.2).

In the game: a notice screen first (press any key), then the title with CONTINUE (when you have a
save), NEW GAME, LOAD GAME, CONFIG, GALLERY and EXIT (the port's own addition; it asks Are you sure
you want to quit without saving?).

5. Playing (遊び方)
----------------

5.1 Keyboard and mouse

The same table is on the launcher's Controls page and in the README; the game's guide line at the
bottom of every menu shows the keys for what is on screen.

Keys / What they do

  Enter / Space / Z / left click
      What they do: Advance the text, decide in menus

  Esc / right click
      What they do: System menu in the story (save, load, config, flowchart, title); back in menus;
      on the title, asks to quit

  X
      What they do: Back in menus; hide or show the message window

  H
      What they do: Hide or show the message window

  Arrow keys
      What they do: Move the cursor; Up opens the mode panel in the story

  W / A / S / D
      What they do: Move the cursor in the menus (same as the arrow keys; in the story they do
      nothing, except that A toggles auto mode)

  Q / E
      What they do: Previous / next tab or page in menus

  Ctrl (held)
      What they do: Fast-forward

  Tab / middle click (wheel button)
      What they do: Toggle latched skip

  A
      What they do: Toggle auto mode

  Mouse wheel up / Page Up / I
      What they do: Backlog (in the story): voices replay, jump back

  Mouse wheel / Page Up / Page Down
      What they do: Scroll lists and pages in menus (a page key is five wheel steps)

  Backspace (held)
      What they do: Rewind, page by page (back in menus)

  F5 / F9
      What they do: Quick save / quick load

  N / B
      What they do: Next / previous scene (both ask first)

  V
      What they do: Replay the voice

  M
      What they do: System menu; copy a slot in the save list

  Delete
      What they do: Delete the slot under the cursor in the save list

  Alt+Enter / F11
      What they do: Fullscreen on / off (the same as Config › System › Display Mode)

  F12
      What they do: Screenshot (section 5.5). Print Screen and its combinations stay Windows' own

  Close button, Alt+F4
      What they do: The game's quit question; Yes ends the game, a second close while it is up ends
      it at once

More with the mouse: the pointer at the top edge of the window opens the mode panel, at the bottom
edge hides the message window; a drag from the middle of the screen to the right fast-forwards and
to the left rewinds while held; in menus you can drag scroll bars and slider knobs, click a scroll
bar's track for a page, and click the words of the guide line (Back, Confirm, Delete Data, the
shoulder pair). In the flowchart and the CG viewer, drag to pan, click a node or the picture, wheel
to zoom the picture.

5.2 Game pads

Plug in a pad at any time, also while the game runs. South button = decide, east = cancel, west =
system menu, north = backlog, shoulders = auto / skip, left trigger (held) = rewind, right trigger
(held) = fast-forward, start = quick save, d-pad or left stick = cursor. The on-screen button hints
follow the pad you use (the game's own PlayStation icons, or Xbox glyphs), or the style you pinned
under Button prompts.

5.3 Skip, auto, rewind, backlog

- Fast-forward: hold Ctrl (or the right trigger). Skip: Tab (or the wheel button) latches it on and
  off. Whether skipping stops at unread text is the game's own setting in Config, as on the PS4.
- Auto mode: A, or a shoulder button; the text speed and the auto speed are the game's own settings
  in Config.
- Rewind: hold Backspace (or the left trigger) to go back page by page.
- Backlog: wheel up, Page Up or I; voices replay there, and you can jump back to a line.
- The mode panel: Up, or the pointer at the top edge, slides in a panel with previous scene, rewind,
  auto, skip, next scene, quick save / load and the voice replay.

5.4 Saves and quick save

Esc (or the right mouse button) opens the system menu with Save, Load, Config, Flowchart and Title.
The save list has 140 slots (manual, auto and quick slots) with thumbnails; F5 / F9 are quick save
and quick load; Delete removes the slot under the cursor and M copies it. At a chapter start the
game asks Do you want to save your progress?: No (left) or Yes (right), then Enter or a click.

5.5 Screenshots

F12 saves the picture on the screen, at the window's own size, as
%USERPROFILE%\Pictures\Tsukihime\Tsukihime_<date>_<time>.png, and shows a small Screenshot saved
notice in the bottom-left corner for a second and a half. The notice is never in the picture. Config
> System > Screenshot Notice turns the notice off (the picture is still saved). Print Screen,
Win+Print Screen, Alt+Print Screen and Win+Shift+S are Windows' own screenshot keys and do nothing
in the game, so a Windows screenshot never presses a key in it.

5.6 The port's own rows in Config

The game's Config screen is the PS4's, with a few rows the port adds at the bottom of the tabs:

- System: Display Mode (Windowed / Fullscreen), Window Size (the presets that fit your monitor),
  Screenshot Notice, Copy Text to Clipboard, Text Hooker Output, Text WebSocket (the last three:
  section 6) and Text Window Opacity (0..100 % in 5 % steps; 100 % is the PS4 look; it darkens or
  lightens the message window's background, never the text).
- Sound: Mute in Background (off by default): every sound fades out when the game window loses the
  focus and back in when it returns.
- Controls: Button Prompts (Auto / Keyboard / PlayStation / Xbox).

5.7 Your saves and settings on disk; backups; importing a PS4 save

Everything the port writes for you is in %APPDATA%\Tsuki (paste that into the address bar of a File
Explorer window, or use Saves > Open folder in the launcher):

File / What it is

  save.dat
      What it is: All 140 slots, the system data (what you have read and unlocked) and the game's
      config, in one file. The previous generation is kept as save.dat.bak, and a damaged file is
      set aside and the backup used.

  settings.ini
      What it is: The port's own choices (appendix A).

  game_dir.txt
      What it is: The remembered game folder.

  last_run.log, crash.log
      What it is: The log of the last run started by the launcher, and the log of failures (section
      7.2).

  backups\<date>-<time>\
      What it is: The backups the Saves page makes.

  icons\tsukihime.ico
      What it is: The Arcueid icon built from your copy.

The launcher's Saves page: Back up now copies save.dat and settings.ini into
backups\yyyyMMdd-HHmmss\; the list shows every backup with its date and slot count, and Restore puts
one back after asking (your current save is backed up first, so a restore can be undone; settings
are left as they are). Back up before you try anything new.

Import a PS4 save: if you played the game on a PS4 or in shadPS4, the launcher can take over its 4
MiB save image (savedata000). It looks for one under
%APPDATA%\shadPS4\home\<user>\savedata\CUSA47999 and offers Import it; Choose a file… takes an image
from anywhere. The image is only read, never changed; it replaces save.dat after your current save
has been backed up.

Only one game can run on the same saves at a time: a second Tsukihime.exe says Tsukihime is already
running and ends.

6. For Japanese learners (日本語学習者向け)
-----------------------------------

The game draws its text from the PS4's pre-rendered glyph pictures, so a text hooker sees nothing of
it by itself. The port therefore offers the plain text of each line in three ways. All three carry
the same text (the line as the backlog shows it: markup and ruby readings removed, a choice list one
line per choice, the speaker's name on a line above when the game shows a name plate), each line
once, when it starts displaying, as one whole line (never letter by letter).

1. Text Hooker Output (on by default): LunaHook / LunaTranslator, Textractor. Start the game (PLAY,
or Tsukihime.exe). In the hooker, attach to the process Tsukihime.exe (LunaTranslator: Select game
or the process list; Textractor: Attach to game). Tsukihime.exe is a 64-bit program, so use the
hooker's x64 build. Advance one line in the game, then pick the text thread that shows it: the
thread is named after a Windows text function, ExtTextOutW (the usual pick), TextOutW or
GetTextExtentPoint32W; all three carry the same text. No H-code is needed. The port passes each line
once through these functions on an invisible drawing surface; nothing is drawn anywhere by them.
Config > System > Text Hooker Output turns this off. This was not tried with a real hooker running
during development (section 1.1); the functions are the ones these programs hook by default.

2. Text WebSocket (off by default): browser texthooker pages with Yomitan. Switch on Config > System
> Text WebSocket (or put text_websocket=on into settings.ini). The game then listens on
ws://127.0.0.1:6677 (texthooker-ui's default address) and sends each new line as one text message to
every connected page; a page that connects while a line is on screen gets that line at once. Open
your texthooker page, let it connect, and read with Yomitan. The server listens on the local machine
only, so no firewall prompt appears and nothing from outside can connect. A small notice says Text
WebSocket: ws://127.0.0.1:6677 when it starts, or why it could not (a port in use: change
text_websocket_port= in settings.ini; there is no row for it in the game).

3. Copy Text to Clipboard (off by default): clipboard watchers. Config > System > Copy Text to
Clipboard puts each new line on the Windows clipboard for Yomitan's clipboard monitor, Textractor's
clipboard thread, or the "clipboard" input of a translator. A notice says Text copied to the
clipboard once per session, at the first copy.

7. Troubleshooting (トラブルシューティング)
--------------------------------

7.1 The messages and what they mean

The launcher speaks English; the game speaks the language you chose (Japanese, English or Chinese),
so the game's messages below appear in that language on your screen.

You see / It means / What to do

  Not chosen yet. Point the launcher at your CUSA47999 folder. / Choose your game folder first.
      It means: No game folder has been chosen
      What to do: Game files > Browse… (section 3.4)

  The remembered folder is gone. / The game folder … no longer exists.
      It means: The folder was moved, renamed, or is on a drive that is not connected (or whose
      letter changed)
      What to do: Connect the drive, or choose the folder again

  eboot.bin is not in this folder. / No eboot.bin in this folder. / That folder does not contain
  eboot.bin. / … holds no game: no folder with eboot.bin and image\ was found in it, not even one or
  two levels down.
      It means: The chosen folder is not the game
      What to do: Choose the CUSA47999 folder (the one with eboot.bin and image\), or a folder at
      most two levels above it

  A .pkg file was chosen: extract it first, then choose the extracted CUSA47999 folder. / … is a PS4
  package file (.pkg). Extract it first (shadPS4, or a PKG extractor) …
      It means: A sealed package was chosen; the port reads extracted folders only
      What to do: Extract it (section 3.2), then choose the folder

  Only the update folder was found; the base game must be beside it. / … holds only the game's
  update (patch) …
      It means: An update folder (category gp, or a -patch / -UPDATE name) without the base game
      next to it
      What to do: Put the base game folder beside it (section 3.3), or choose the base game folder

  Several game folders are inside the chosen one; choose one of them.
      It means: The folder above holds more than one game
      What to do: Choose the CUSA47999 folder itself

  The game files are not complete: see the problems on this page. / The game folder is incomplete: …
  is missing from … / a list of failed checks on the Game files page
      It means: A file of the dump is missing or damaged (an interrupted extraction, a dump of part
      of the game)
      What to do: Compare with the tree in section 3.3; extract or dump again. The failed checks
      name the files

  This copy of the game (…, eboot.bin SHA-256 …) is a build the port does not know, and these tables
  could not be found in its program: … Please report it together with the log file.
      It means: Your eboot.bin is a build the port has never seen, and part of what it needs could
      not be located in it
      What to do: The game cannot run on this copy. Report it (section 7.3)

  A small notice Not the verified build: … when the game starts; Ready, but not the verified build
  in the launcher
      It means: Your build is not the one the port was played on, but everything it needs was found
      What to do: Nothing; play. If something looks wrong, say so in a report, with the Build row's
      text

  The FFmpeg libraries are missing next to Tsukihime.exe (avcodec-63.dll, …) / Ready check:
  avutil-61.dll is missing (and 3 more)
      It means: One of avutil-61.dll, swresample-7.dll, avcodec-63.dll, avformat-63.dll is not
      beside Tsukihime.exe
      What to do: Unzip the whole release again into the same folder. If an antivirus quarantined a
      file, restore it: these are FFmpeg's own unmodified libraries (licenses\FFmpeg-SOURCE.txt says
      which build)

  Tsukihime.exe is not next to the launcher
      It means: The zip was not unpacked whole, or files were moved
      What to do: Unzip the whole release again

  Your graphics driver does not provide OpenGL 3.3. / The game window could not be created.
      It means: The graphics driver gave no OpenGL 3.3 context (an old or generic driver, a
      remote-desktop session, a virtual machine, a laptop with a very old or generic driver)
      What to do: Install the current driver from Intel, AMD or NVIDIA (on a laptop, the laptop
      maker's or Intel's / AMD's driver; Windows' basic display driver has no OpenGL 3.3); a laptop
      with two graphics chips can run the game on either (Windows Settings > System > Display >
      Graphics); do not run over Remote Desktop

  Tsukihime is already running. / The game is already running. / The game is already running in
  another window.
      It means: A second game on the same saves was refused
      What to do: Use the one that is open. If none is visible, end Tsukihime.exe in Task Manager

  The Tsukihime launcher is already open.
      It means: A second launcher was refused
      What to do: The first one comes to the front

  The save file could not be written: … Saves made now are kept until the game closes only. / Ready
  check: The save folder cannot be written: … / save.dat is a folder, not a file
      It means: %APPDATA%\Tsuki cannot be written (permissions, a full disk, a folder named
      save.dat)
      What to do: Free space or fix the permissions of %APPDATA%\Tsuki; rename a folder called
      save.dat. Saves made in the meantime are lost when the game closes

  Your save file was damaged, so the previous generation (save.dat.bak) was used instead … / Your
  save file was damaged (…) … a new profile was started. The launcher's Saves page can restore a
  backup.
      It means: save.dat could not be read; the damaged file was moved aside (the message says
      where)
      What to do: Check the Saves page and restore a backup if you have one

  The log file … could not be opened: … The game goes on without a log file.
      It means: The launcher's log file is locked or its folder read-only
      What to do: Close other copies; check %APPDATA%\Tsuki

  The text WebSocket could not start on port 6677: …
      It means: Another program uses that port
      What to do: Put another text_websocket_port= into settings.ini and let your page connect there

  The game closed with an error (code N). Press Log to see why.
      It means: The game ended with a failure
      What to do: Press Log; the last lines say what happened. Report it (section 7.3)

  The game opens fullscreen when you wanted a window (or the other way round)
      It means: The Fullscreen switch of the launcher, or Alt+Enter / F11 in the game, decided the
      last mode
      What to do: Set the switch on the Display page (the launcher passes it on every PLAY), or
      press Alt+Enter in the game; Config > System > Display Mode shows the current mode

  The window is smaller than the size you chose
      It means: A size that does not fit the monitor's work area (90 % of it at most) is scaled down
      What to do: Pick a preset the Display page offers; the note under the presets says the size
      the game opens with

  No sound, or sound only sometimes
      It means: Volumes are in the game's own Config > Sound; Mute in Background fades the sound out
      while another window has the focus
      What to do: Check Config > Sound and the Windows output device; the log counts audio failures

  The language you want is not offered
      It means: Your copy does not carry it (the Languages row on Game files says what it has)
      What to do: Nothing to do in the port; the voices are Japanese in every language anyway

  Windows: Windows protected your PC
      It means: SmartScreen does not know the publisher (the programs are not code-signed)
      What to do: More info > Run anyway, once per program

7.2 Where the log is

- %APPDATA%\Tsuki\last_run.log: the log of the last run started from the launcher (PLAY passes --log
  with that path). The Log button in the launcher's footer, and Open the log on the Help page, open
  it in Notepad. Its first line names the port's version and the FFmpeg build; the lines layout:,
  build:, languages: and tables: say what was found in your folder; window: and window mode: say how
  the window was placed; a failure is at the end.
- %APPDATA%\Tsuki\crash.log: appended to whenever the game fails, however it was started; the error
  box names it (Details: …).
- A game started directly (Tsukihime.exe, the desktop shortcut) writes no last_run.log. To get a log
  of such a start, start it from the launcher instead, or start Tsukihime.exe --log <file> from a
  command prompt (appendix B).

7.3 How to report a problem

Give the people who look after the port:

1. The log: last_run.log from a start through the launcher that showed the problem (and crash.log if
   the game failed).
2. What the launcher says about your copy: the Build and Languages rows of the Game files page and
   the Status line (or the chip under the banner: CUSA47999 · game version 01.01, with not the
   verified build if it says so). The build: line of the log carries the same; for a build the port
   does not know it adds the size and the SHA-256 of your eboot.bin.
3. Your machine: Windows version, graphics card, one or two monitors, keyboard / mouse / pad.
4. What you did, step by step, and what you saw.

Attach no game files (no archives, no eboot.bin, no movies, no param.sfo): they are the game's
copyrighted data, and the log already says everything the port knows about them. A screenshot of an
error message is useful; pictures of the game's own content are not needed.

7.4 What to try first

1. Unzip the whole release again into one folder; start the launcher and read the Ready check.
2. On Game files, press Check again; choose the folder again if the status is not Ready.
3. Update the graphics driver (Intel, AMD or NVIDIA; on a laptop, the laptop maker's or Intel's / AMD's
   driver). Integrated graphics are fine; nothing needs a gaming card.
4. Saves > Back up now, then try the change you were about to make.
5. Start the game from the launcher so that last_run.log is written, reproduce the problem, press
   Log, and read the last lines.

Appendix A: settings.ini (設定ファイル)
---------------------------------

%APPDATA%\Tsuki\settings.ini is a text file of key=value lines, read once when the game starts. The
launcher writes it; you can edit it with Notepad (a # starts a comment; unknown keys and bad values
are ignored).

Key / Values / Effect

  prompts
      Values: auto, keyboard, playstation, xbox
      Effect: Button prompts (Config > Controls writes it too)

  fullscreen
      Values: on, off
      Effect: The launcher's choice for the next PLAY; the game stores the mode in save.dat and
      removes the line

  language
      Values: ja, en, zc, zt
      Effect: The game language of the next start; applied once, then removed (Config changes it
      later)

  window
      Values: 1600x900 (640x360 up to 16384x16384)
      Effect: The window's size when not fullscreen (default 1600x900; clamped to 90 % of the
      monitor's work area)

  monitor
      Values: x,y
      Effect: The monitor to open on, by the top-left corner of its desktop area (0,0, 1920,0,
      -2560,0)

  vsync
      Values: on, off
      Effect: Wait for the monitor's refresh (default on)

  mute_in_background
      Values: on, off
      Effect: Config > Sound > Mute in Background (default off)

  copy_text
      Values: on, off
      Effect: Config > System > Copy Text to Clipboard (default off)

  text_hooker
      Values: on, off
      Effect: Config > System > Text Hooker Output (default on)

  text_websocket
      Values: on, off
      Effect: Config > System > Text WebSocket (default off)

  text_websocket_port
      Values: 1..65535
      Effect: The WebSocket's port (default 6677); no row in the game, edit the file

  screenshot_notice
      Values: on, off
      Effect: Config > System > Screenshot Notice (default on)

Appendix B: starting the game from a command line (コマンドライン)
-----------------------------------------------------------

Tsukihime.exe --help | more in a command prompt opened in the port's folder prints every switch (the
game is a windowed program, so its text output shows only through a pipe). The ones a player may
want:

Switch / Effect

  --game <folder>
      Effect: Use this game folder for this run (else the TSUKI_GAME_DIR environment variable,
      else the remembered game_dir.txt, else the folder dialog)

  --lang ja|en|zc|zt
      Effect: The language of a new profile for this run

  --fullscreen, --windowed
      Effect: The window mode of this run (remembered for the next)

  --save-dir <folder>
      Effect: Keep saves, settings and the log of this run in another folder than %APPDATA%\Tsuki

  --log <file>
      Effect: Write the run's log to this file

  --prompts auto|keyboard|playstation|xbox
      Effect: The button prompts for this run

  --screenshot-dir <folder>
      Effect: Where F12 saves for this run (default Pictures\Tsukihime)

The launcher has --game <folder> and --data <folder> (another profile folder) for the same purposes.
